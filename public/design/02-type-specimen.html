1.0 Why three families and one weight

{{ f.pangram }}
{{ f.name }} {{ f.role }}
{{ f.why }}
{{ f.spec }}
One weight is a constraint, not an oversight. Libertinus ships no true bold for the sans, and rather than fake one the system carries hierarchy on size, family and colour. The practical effect is that a table cannot be emphasised into legibility: it has to be laid out correctly instead. Italic exists in the serif and is used for a defined term or a quiet aside, never for emphasis in running interface text.
2.0 The scale {{ stepLabel }}
Fourteen steps on a roughly 1.2 ratio, tightened at the display end where tracking does more work than size. Every step names the one thing it is for. A size not on this list does not appear in the product.
