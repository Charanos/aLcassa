1.0 Button {{ stateLabel }}
Four variants, no more. One primary to a view, and it names the action rather than agreeing to it. There is no icon-only primary: an action that provisions or destroys a tenant is written in words, because the audit entry it produces is also in words.
Disabled is drawn with its own fill and ink rather than an opacity, so its contrast is a decision. A control unavailable because of a plan limit stays in the layout with the limit stated beside it; hiding it would make an entitlement look like a missing feature.
Busy keeps the button's width and swaps only the glyph, so a toolbar does not reflow while a tenant provisions. The focus ring is copper at the same width in both themes and never inherits the variant's hue — on a destructive button the ring is deliberately not red.
