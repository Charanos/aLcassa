1.0 Panel Header · body · footer where it saves
The header is a serif title, an optional caption and at most one action. The footer exists only when the panel holds a form, and it carries the save. A panel with no footer never needs saving, which is how a reader tells a settings panel from a display one before reading a word of it.

2.0 Data grid {{ rowLabel }}
The one table in the system. Rows are separated by hairlines rather than by fill, because zebra striping and a status tint cannot occupy the same row. A brand mark leads each row at 32, with the hashed initial as its fallback.
Identifiers and counts are mono and range right, so a ceiling is read down a column rather than across a row. Names are sans and range left. The header row is micro caps, sticks on scroll, and shows one sort arrow on one column only.
The whole row navigates. The overflow glyph is the only other target inside it and is 44 wide, so the two never contend for the same pixels. Selection is opt-in per screen and adds a leading checkbox column rather than changing the row.
